# 论坛小脚本 - 全能看帖与提取辅助

> Tampermonkey 油猴脚本，运行在 sehuatang.net 论坛，提供无缝翻页、资源提取、115网盘离线下载等功能。

## 版本

当前版本：**v15.17**

## 安装与更新

安装地址（分支固定为 `main`）：

```
https://raw.githubusercontent.com/1210418430/customviewed98t/main/brower.js
```

- 脚本头部通过 `@downloadURL` / `@updateURL` 指向该地址，油猴会自动检查更新
- **不要再用 `master` 分支的地址**（该分支已删除，会 404）
- 从旧版本升级：旧版本内置的是已失效的 `master` 地址，无法自动更新，
  需在油猴里删掉旧脚本后从上表地址重新安装一次（配置项存在 GM 存储里，重装不会丢）

## 115 网盘 API

| 操作 | 端点 | 方法 |
|------|------|------|
| 获取认证 | `https://115.com/?ct=offline&ac=space` | GET |
| 推送单条 | `https://115.com/web/lixian/?ct=lixian&ac=add_task_url` | POST |
| 创建文件夹 | `https://webapi.115.com/files/add` | POST |
| 列出文件夹 | `https://webapi.115.com/files?aid=1&cid={cid}&show_dir=1&format=json` | GET |

推送请求体：`uid={uid}&sign={sign}&time={time}&wp_path_id={cid}&url={encoded_url}`

## 内联 ZIP 读取器

不依赖外部库，使用浏览器内置 `DecompressionStream` API：

1. 倒序查找 EOCD（PK\x05\x06），定位中央目录
2. 遍历中央目录条目，收集 .txt 文件的准确元数据（compSize 永远准确）
3. 根据 localOff 定位数据，用 deflate-raw 解压

支持：stored（无压缩）、deflate（压缩）。不支持的格式自动回退到 JSZip。

## 种子转磁力

1. 下载 .torrent 文件
2. bencode 解析，定位 info 字典的原始字节范围
3. SHA-1 哈希 info 原始字节 → `magnet:?xt=urn:btih:<HASH>`

## 变更日志

### v15.17
- **修复多列卡片内图片被强制放大**：卡片布局里给 `img` 加了 `width:100% !important`，
  导致很小的图被撑满卡片宽度。现改为只做 `max-width:100%` 上限、宽高按原始比例
  （`width:auto`），小图恢复原始尺寸，大图仍受设置里的「图片最大高度」限制；
  纵向堆叠模式下每张图独占一行（横向滚动模式不受影响）
- **修复「一键回复」后自动刷新导致页面整体上跳（看着像后退一下）**：
  刷新时原先会先 `remove()` 旧内容再重新请求，卡片高度骤降被浏览器钳制滚动位置，
  再用 `window.scrollTo` 补偿反而更飘。现改为**原地替换**：旧内容保留（半透明 + 禁点击）
  直到新内容就绪，高度不塌陷，同时删除补偿性的 `scrollTo`
- 刷新按钮修复：刷新失败或成功后会恢复文字与可用状态（原先刷新一次后按钮永久置灰）
