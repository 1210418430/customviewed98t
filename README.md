> Tampermonkey 油猴脚本，运行在 sehuatang.net 论坛，提供无缝翻页、资源提取、115网盘离线下载等功能。

## 版本

当前版本：**v15.25**

## 安装与更新

安装地址（分支固定为 `main`）：

```
https://raw.githubusercontent.com/1210418430/customviewed98t/main/brower.js
```

- 脚本头部通过 `@downloadURL` / `@updateURL` 指向该地址，油猴会自动检查更新
- **不要再用 `master` 分支的地址**（该分支已删除，会 404）
- 从旧版本升级：旧版本内置的是已失效的 `master` 地址，无法自动更新，
  需在油猴里删掉旧脚本后从上表地址重新安装一次（配置项存在 GM 存储里，重装不会丢）

## 内联 ZIP 读取器

不依赖外部库，使用浏览器内置 `DecompressionStream` API：

1. 倒序查找 EOCD（PK\x05\x06），定位中央目录
2. 遍历中央目录条目，收集 .txt 文件的准确元数据（compSize 永远准确）
3. 根据 localOff 定位数据，用 deflate-raw 解压

支持：stored（无压缩）、deflate（压缩）。不支持的格式自动回退到 JSZip。

## 种子转磁力

1. 下载 .torrent 文件
2. bencode 解析，定位 info 字典的原始字节范围
3. SHA-1 哈希 info 原始字节 → `magnet:?xt=urn:btih:<HASH>`

## 变更日志

### v15.25
> 针对"切双列后卡顿、点不动、只渲染一半"的主线程优化

- **卡片初始化分帧**：长列表不再一次性同步处理（实测 162 张卡片从 1.24s 长任务变成
  `218ms` 内完成、长任务拆成 `197/112/61/67ms`），每帧只处理一小批，滚动和点击不再被冻住
  - 后台标签页里 `requestAnimationFrame` 不触发，自动退化成 `setTimeout`
- **两处 `MutationObserver(document.body, subtree)` 合并到一帧**：`_checkVisibility`（读
  `scrollHeight`）与快捷跳转按钮的 `syncPos`（读 `offsetLeft/offsetTop`）原来每次 DOM 变化
  都会强制一次同步布局，现在用 rAF 合并，并且改读 `style.left/top` 不再碰布局
- **滚动监听节流**：无缝翻页判定从"每个 scroll 事件读一次 `body.offsetHeight`"改成 rAF + 0.6s 冷却；
  折叠按钮定位、跳跃按钮定位同样合并到帧
- **悬浮预览单飞**：同一时刻只允许一个预览请求，鼠标划过一排卡片不会再触发一串整页
  `DOMParser` 解析（每个都是几十毫秒的主线程开销）
- **大选区跳过**：拖选跨整页（共同祖先是 body/table）时不再调用 `selection.toString()`
- **滚动小球拖拽兜底**：窗口外松开鼠标 / 窗口失焦时补发 `mouseup`，避免拖拽状态卡死
  （表现为页面自己滚动、点不动、光标停在抓手上）
- **新增设置项「📌 标题吸顶（多列布局）」**：可关闭吸顶，省掉每张卡片的 sticky 计算，
  卡顿时可以关掉对比
- **新增卡顿自检**：主线程单任务超过 300ms 会在控制台打印 `[卡顿自检] 主线程被占用 xxx ms`，
  方便定位

### v15.19
- **修复 v15.18 标题吸顶完全无效**：`position: sticky` 会被**任何** `overflow` 不为 `visible` 的祖先元素
  截断——它会把那个祖先当成"滚动容器"，而那个容器本身从不滚动，于是标题一动不动。
  本论坛 `div.mn`（列表主体外层）就带 `overflow: hidden`（清浮动用的），这就是吸顶失效的根因。
  - 新增 `unblockStickyAncestors()`：从卡片标题向上遍历到 `<html>`，把 `overflow:hidden` 的祖先
    就地改成 **`overflow: clip`**——裁剪效果和 hidden 一样，但**不会产生滚动容器**，sticky 才能相对视口生效
  - 同时补 `display: flow-root`，把 `overflow:hidden` 顺带建立的 BFC（清浮动 / 阻止外边距合并）效果保住，
    实测页面各区块高度、页脚位置与改动前完全一致（若改用 `overflow: visible` 会让整页位移 15px）
  - 关闭多列布局时 `restoreStickyAncestors()` 完整还原被改过的样式
  - 排查辅助：控制台执行 `__customStickyDebug()` 会打印标题到根元素的 overflow 链
- 已知表现：吸顶条高度 = 该卡片标题区（标题 + 可复制文本 + 标签）的原始高度，长标题卡片可能到
  150-220px；若觉得占屏，可调小 `--custom-sticky-top` 或告知行数以做折叠
